About This App

The "PLU Finder" is a static web app that helps users associate product names to corresponding PLUs(Product Lookup Codes). This app seeks to help new employees or temporary cross functioning employees by providing them with tips and information relevant to their working area.

Currently, the main purpose of this web app is to provide a secondary method of PLU visualization. For some departments, a visual aid of products in question will improve PLU familiarization and better optimize time spent at a department.

A quick reference tool. Simple, but effective.

Use Cases

  • Cashier: Quick search produce PLUs while at a checkout register.

  • Meat Market/Deli: Applicable when printing price tags for meat products.

  • Deli/Curbside: (Soon)Recommend a substitution for a product.

  • Seafood: (Soon)Suggest cooking style for product.

  • Bakery: (Soon)Baking time and temperature reminder for bread and pastries.

Disclaimer

The developer has created this tool with the intent to demonstrate his abilities to build and deploy a web application. "PLU Finder" is designed to perform in a real-world situation for educational purposes only. Presently, this app is tailor made to suit the needs of one specific store location.

This tool is not endorsed by any business. While grocery store employees are encouraged to use this tool and provide feedback, this app is not an official tool and should not replace any official systems or processes. Employees are to use this tool as supplement alongside their already existing official systems or processes.
